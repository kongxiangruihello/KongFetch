KongFetch 3.0
原生 macOS 应用，macOS 13 或更新系统。支持 Apple 芯片与 Intel。

安装
退出旧版，将安装包中的 KongFetch.app 拖入 Applications 替换，再打开。
安装包使用本地签名，未使用 Developer ID 或 Apple 公证。
更新后系统可能需要重新确认输入监控权限。若双 Control 无反应，请在系统设置 → 隐私与安全性 → 输入监控中移除旧 KongFetch 条目，再添加 /Applications/KongFetch.app 并允许，退出后重新打开。
快捷键需要 KongFetch 正在运行；设置中可开启登录启动。

本版实现第 2–7 项
2. 真实唤起检测
设置 → 唤起诊断 → 测试双 Control。关闭窗口后切到其他应用，快速按下并松开 Control 两次。
报告分别显示收到事件、窗口是否可见、搜索框是否获得焦点；并区分其他应用前台与本应用前台的识别。
12 秒未收到事件会重新显示窗口并提示检查权限，不会直接报告测试成功。
诊断包含后台事件、监听状态及实际运行版本和路径。窗口最小化后唤起会还原，并尝试切到当前桌面和获得输入焦点。

3. 本地 OCR
⌘K → 建立本地 OCR 索引 → 选择图片和扫描 PDF 所在文件夹。
识别文字只保存在本机，原文件不被修改，无第三方识别服务。
建立索引后，顶部搜索方式选择“文件内容”，输入正文关键词；结果展示 OCR 摘要和命中文字。
支持系统可识别的图片格式及 PDF；中文简体、繁体和英文。OCR 准确度受画质、字体和版式影响。
每文件最多 100 MB；PDF 最多前 30 页；文字最多 50 万字符，达到限制会提示。
未下载的云文件、加密 PDF、不可访问文件会跳过；可以取消，已完成的缓存保留。
仅已建立 OCR 索引的文件可参与 OCR 搜索，且遵守当前搜索范围、类型、筛选和排除目录。
索引文件夹不自动加入全用户搜索范围；额外位置请在“搜索目录与索引”中添加，或切换到该目录搜索。
文件修改、移动或重命名后旧文字缓存不再匹配，需要对相应目录重新建立 OCR 索引。
⌘K 可以取消 OCR 或清除文字缓存；清除缓存保留原文件。

4. 自然语言筛选
直接输入：最近一周的 PDF、大于100MB的视频、昨天的合同的PDF、标签:工作 合同。
支持今天、昨天、最近/近 N 天或 N 周、一周、一星期、一个月；日期按修改时间与本地日历计算。
大小支持大于/超过/小于/不足及 KB、MB、GB，采用十进制单位，大小比较为严格大于或小于。
支持 PDF、视频、图片、音频、文档、文件夹；标签语法为 标签:名称、tag:名称、#名称。
识别出的条件会显示在筛选摘要中，悬停可查看完整条件；“清除”可以移除筛选。

5. 文件操作与撤销
选中结果 → ⌘K → 重命名、移动到文件夹、移到废纸篓。
移动与废纸篓支持多个选中项目；废纸篓操作需要在应用内确认。
⌘K → 撤销文件操作，可撤销重命名、移动、移到废纸篓和标签添加。
最多保留本次运行中的 20 个操作，每个文件分别一条；退出应用后撤销记录不保留。
同名目标不会被覆盖；撤销时原位置已占用会提示失败并保留记录，解决冲突后可再试。
跨磁盘移动较大文件可能需要等待；移动后可继续使用系统文件管理恢复或调整。

6. 访达标签与颜色
选中结果 → ⌘K → 添加访达标签，多个标签用逗号或中文逗号分隔，保留原有标签。
输入红色、橙色、黄色、绿色、蓝色、紫色、灰色可添加对应颜色；一次选择多个颜色时采用第一个颜色。
⌘K → 按访达标签筛选；或搜索 标签:工作 合同、标签:红色。
标签按完整名称匹配，留空可清除手动标签筛选。手动标签与自然语言标签同时存在时需同时满足。
标签筛选与自动节能设置也包含在设置备份中。

7. 后台索引与资源控制
默认启用自动节能；电池供电、低电量模式、高温或系统繁忙时，名称索引和 OCR 在扫描批次间减速。
目录变化较密集时增加合并等待，OCR 使用单个后台识别队列，正文缓存搜索也在后台进行。
⌘K → 后台索引与资源，查看扫描数量、队列、OCR 进度、减速原因、CPU 采样和峰值内存。
CPU 首次打开建立基准，稍后“刷新”查看；单核满载为 100%。内存显示本次进程峰值，不是当前占用。
可关闭或启用自动节能，新设置从下一次扫描开始应用。
这是协作式减速，不是固定 CPU 或内存硬上限；单次 OCR 请求完成前可能暂时增加占用。

保留功能
中文、拼音、文件名与路径匹配；首选结果与反馈；Quick Look；收藏与别名；目录快捷键；拖拽；设置备份。
主窗口 750×474 点，搜索输入框保持垂直居中，保留放大的菜单栏图标。

验证
Apple 芯片上已通过 3.0 新功能专项检查及原有搜索、预览、升级、备份、结果反馈和 Control 双击识别检查。
真实生成的中文图片与扫描 PDF 完成 OCR、缓存保存和正文命中测试；验证文件撤销、废纸篓恢复、目标冲突保护、标签和日期大小筛选。
实际界面检查已验证标签添加、颜色显示、OCR 建立索引后正文搜索、命中摘要、预览、资源面板与固定窗口。
两个架构编译通过，安装包本地签名严格检查通过；Intel 未在实机运行。
新版本安装后的真实跨应用双 Control 仍需用户按实体键测试，并确认系统输入监控权限。
