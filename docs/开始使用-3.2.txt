KongFetch 3.2 使用说明

本版新增八项
1. 漏搜诊断：操作面板搜索“漏搜诊断”，选中未找到的文件或文件夹，检查范围、目录排除、读取权限、关键词与索引。可修复目标附近目录，不会重建其他目录。
2. 高级搜索："年度合同" 连续文字；合同 -草稿 排除词；ext:pdf 合同；ext:pdf,docx 多种扩展名；-ext:zip 排除扩展名。支持组合自然日期、大小和标签。引号内“今天”等词按普通文字搜索。内容模式的短语和排除词针对正文；名称/路径模式分别针对名称/路径。
3. 搜索操作面板：⌘K 后输入操作名，↑↓ 选择，回车执行；显示当前快捷键，灰色项需先选文件。包含原有文件操作、常用搜索、排序和设置。
4. 连续目录搜索：选中文件夹后 ⌘→，保留关键词搜索其内部；⌘← 返回之前的关键词、范围、筛选、选择与滚动位置。回车或双击文件夹直接浏览。历史最多30层，仅本次运行保留。
5. OCR 文字：选中已识别且缓存有效的文件，操作中打开“OCR 文字”，可选择复制、复制全部、导出 UTF-8 TXT 或搜索选中文字。选中文字最多300字符。文件变化后需等待重新识别。导出不能覆盖原文件。
6. 重复文件：选择目录后开始，按大小再按完整内容 SHA-256 分组；支持取消、预览、打开、访达定位、复制路径。不会自动删除。跳过隐藏项、符号链接、程序包、排除目录、未下载云文件及常见缓存/开发目录。空文件也会分组，硬链接不重复计算空间；统计是潜在重复字节，不代表可直接释放的磁盘空间。上限10万文件、20万遍历项、512GB核对读取量，达到上限会提示。
7. 中文与键盘：候选词选择期间不拦截方向键、回车或 Esc；⌘1–9 打开前九项。后台更新尽量保持当前选择和可见位置，手动操作后以您的选择为准。
8. 剪贴板历史：⌃⌥V 全局打开，首次点击“启用记录”后开始。支持文字、图片、文件引用，搜索、固定、删除、清空、暂停和再次复制。双击/回车复制选中项，再到目标应用粘贴。内容只保存本机，不上传 GitHub，也不包含在设置备份中。

剪贴板限制
最多200项、总24MB；未固定内容保留30天，最多固定50项。每项文字最多200KB、图片4MB、文件引用100个；只保存引用，不读取或复制原文件。固定也占用总容量。暂停期间及启用前的内容不补录。
敏感标记内容和默认密码应用跳过；未标记的私密内容仍可能被记录，可暂停或在“不记录的应用”中选择应用排除。历史文件在 ~/Library/Application Support/KongFetch/Clipboard，以当前账户权限保存，没有额外加密。

快捷键
⌃⌥V：剪贴板历史（默认全局）。保留原来的唤起与操作组合。
“操作 → 操作快捷键”可以为剪贴板、漏搜诊断、重复文件、OCR文字以及原操作设置应用内/全局触发，并检查冲突。应用需保持运行。⌘1–9、⌘←、⌘→保留给结果导航。

安装与验证
原生 macOS13+，Apple芯片与Intel通用安装包；主窗口750×474点。退出旧版，将KongFetch.app拖入Applications后打开。本版未覆盖电脑中的已安装应用；安装由您完成。
采用本地ad hoc签名，尚未使用Developer ID与Apple公证。双Control更新后可能需重新确认输入监控；如失效，在输入监控中移除旧条目并重新添加/允许Applications中的KongFetch，退出后重新打开。
本版隔离测试不读取真实剪贴板历史、不修改通用剪贴板、不替换已安装应用。Apple芯片上编译与运行验证，Intel仅完成编译。

此前功能及说明

KongFetch 3.2 · 原生 macOS 应用
支持 macOS 13 或更新版本，安装包包含 Apple 芯片与 Intel 两种架构。

安装
退出旧版，将 DMG 中的 KongFetch.app 拖入 Applications，再打开。
应用运行时，全局组合键和双 Control 才会生效。可在设置中启用登录启动。
这是本地 ad hoc 签名版本，尚未使用 Developer ID 或 Apple 公证。
更新后如双 Control 无效，在系统设置→隐私与安全性→输入监控中检查 KongFetch。
必要时移除旧条目，重新添加 /Applications/KongFetch.app，允许后退出并重新打开。
可从“操作→唤起诊断”检查事件、窗口和输入焦点。

本版功能
1. 顶部选择“名称：精确”“名称：模糊”“名称及路径”“文件内容”。
   默认模糊名称支持缩写、中文拼音；精确名称匹配完整文件名或不带扩展名的名称。
   名称模式不再仅因为父目录含关键词而匹配子文件；按路径找文件时切换到“名称及路径”。
   搜索别名和手动首选结果仍可优先匹配。名称索引和 Spotlight 合并后最多显示 2000 项。
2. 操作→OCR 管理，添加包含图片或扫描 PDF 的目录。目录会保存在本机并持续监听。
   启动时检查缓存，文件新增、修改、移动后自动更新；每五分钟再复查一次目录，
   用于恢复遗漏的文件事件；磁盘断开、权限或识别错误显示原因。
3. “文件内容”模式中的 OCR 命中显示图片关键词框、PDF 页码和上一处/下一处定位。
   原文件不修改。旧版缓存可继续搜索；在所选目录重新识别后才有定位信息。
4. OCR 管理可查看逐文件状态、暂停/继续、重试失败、清理失效或清空缓存。
   暂停会让正在识别的文件处理完；清空缓存后暂停自动识别，点击继续会重建。
   移除目录停止该目录的自动更新，已识别文字保留，需清空缓存才能删除。
5. 操作→搜索压缩包内部，选择 ZIP 或文件夹，搜索内部文件名或内部路径。
   显示文件名、内部位置及所属 ZIP。仅预览或打开时才解压选中文件到临时目录。
   退出应用清理临时文件；在外部应用中保存修改不会回写 ZIP。
6. 多选文件→操作→批量重命名，输入前缀、后缀、替换文字或编号，先检查名称预览。
   保留扩展名，最多 500 项；冲突时不执行，不覆盖文件。执行后可以整批撤销。
   意外中断时从“恢复未完成的批量重命名”查看恢复预览，再恢复原名称。
7. 操作→检查 GitHub 更新，显示版本说明，用户选择后下载，检查大小、SHA-256、应用签名和版本。
   安装前备份旧版，随后退出并重新打开；可通过“回退到备份版本”选择旧版。
   自动替换仅支持 /Applications/KongFetch.app 或 ~/Applications/KongFetch.app。
   需要管理员权限或从其他位置运行时，显示已校验应用供手动安装。
   校验用于发现损坏和来源异常，不等同于 Developer ID 身份验证或 Apple 公证。
8. 操作→操作快捷键，为每个操作设置组合键，选择“全局”或“应用内”，可启停与恢复默认。
   组合键须含 Command、Option 或 Control。检查与唤起、目录、其他操作和全局注册的冲突。
   冲突时原组合保持有效。全局组合键不依赖输入监控；双 Control 单独使用输入监控。

默认操作快捷键
⌘L：聚焦搜索（应用内）
⌘K：操作菜单（应用内）
⌃⌥2：名称 / 内容搜索（全局）
⌃⌥F：循环切换名称匹配精度（全局）
⌃⌥O：OCR 管理（全局）
⌃⌥Z：压缩包搜索（全局）
⌃⌥R：批量重命名（全局；沿用 KongFetch 所选文件，空选择时可选择文件）
⌘⌥Z：撤销文件操作（应用内；可在设置中改为全局）
⌃⌥U：检查更新（全局）
⌃为 Control，⌥为 Option，⌘为 Command。应用唤起默认 ⌘⌥空格，双 Control 保留。
全局操作遇到对话框或正在进行的批量操作会提示先完成当前操作。

限制与数据位置
OCR 单文件最多 100 MB；PDF 前 30 页；最多 50 万文字、12000 个字符/词的精细位置。
超出位置预算的命中使用整行位置；非扫描 PDF 使用正文行/页面提示，定位精度取决于识别质量。
OCR 管理最多 25000 个任务，缓存仅保存在 ~/Library/Application Support/KongFetch/OCR。
默认跳过隐藏文件、缓存和开发依赖；已排除的目录不会被搜索或识别。
云端未下载文件需先在访达下载；加密 PDF、ZIP64、分卷 ZIP、加密 ZIP 及部分旧编码暂不支持。
ZIP 搜索不查正文；解压仅支持普通文件和常见的储存/Deflate 压缩，单文件最大 100 MB。
撤销最多 20 条，仅当前运行有效；撤销遇到被替换文件或占用名称时停止并保留记录。
恢复日志位于 ~/Library/Application Support/KongFetch/RenameRecovery。
更新备份位于 ~/Library/Application Support/KongFetch/Updates/Backups，可自行在访达整理。
主搜索窗口保留 750×474 点；管理工具使用独立窗口。

名称模式、中文 ZIP 与特殊字符文件名、批量冲突/交换/撤销/中断恢复、全局快捷键和更新回退。
Intel 架构已编译，尚未在 Intel 实机验证。实体双 Control 的权限需在正式安装后检查。
